# Laboratorio
Laboratorio en Java. Desarrolle una solución programada en Java con GUI que tenga dos opciones. 1-Convertir matrices de adyacencia a grafos. La cantidad de nodos la digita el usuario para generar la matriz y de ahi el usuario puede cambiar los valores de la matriz. 2- Dibujar un grafo y que a partir del mismo se genere la matriz de adyacencia.
